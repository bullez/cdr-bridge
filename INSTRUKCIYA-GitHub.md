# Как выложить CDR Bridge на GitHub — инструкция для новичка

Эта инструкция написана для человека, который **никогда не пользовался GitHub**.
Делайте шаг за шагом, ничего нельзя испортить — всё можно удалить и переделать.

**Что у вас должно быть на руках** (вы скачали это из приложения CDR Bridge):

- `cdr-bridge-github.zip` — архив с проектом (внутри уже есть README и инструкция);
- `CDR-Bridge-Portable.html` — портативная версия для раздела Releases;
- этот файл.

---

## Шаг 1. Регистрация на GitHub

1. Откройте в браузере сайт **https://github.com**
2. Нажмите кнопку **Sign up** (справа вверху, зелёная).
3. Введите свою электронную почту → **Continue**.
4. Придумайте пароль → **Continue**.
5. Придумайте **имя пользователя** (логин). Оно войдёт в адрес вашего проекта,
   например: `github.com/ivanov/cdr-bridge` → **Continue**.
6. Введите код из письма (пришлёт GitHub) → регистрация готова.

## Шаг 2. Создаём репозиторий

«Репозиторий» = папка проекта на GitHub.

1. Находясь на сайте GitHub, нажмите **плюсик (+)** в правом верхнем углу →
   выберите **New repository**.
2. Заполните поля:
   - **Repository name**: `cdr-bridge` (можно любое другое, лучше латиницей);
   - **Description** (короткое описание): `Смена версии файлов CorelDRAW и конвертация в SVG/PDF/AI — бесплатно и без установки`;
   - **Public** — обязательно, чтобы проект видели все (стоит по умолчанию);
   - Галочку **«Add a README file»** НЕ ставим — README уже лежит в архиве проекта.
3. Нажмите зелёную кнопку **Create repository**.

Откроется пустая страница репозитория — это нормально.

## Шаг 3. Загружаем файлы проекта

1. Сначала **распакуйте** `cdr-bridge-github.zip` на компьютере
   (правый клик → «Извлечь всё…» в Windows). Внутри появится папка, например
   `cdr-bridge-github`, а в ней файлы проекта (`src`, `public`, `package.json`,
   `README.md` и др.).
2. На странице репозитория GitHub найдите ссылку **«uploading an existing file»**
   (в центре страницы) — или кнопку **Add file → Upload files**.
3. Откройте на компьютере распакованную папку, нажмите **Ctrl+A**
   (выделить всё) и **перетащите** все файлы и папки в окно браузера
   в область загрузки.
4. Дождитесь, пока все файлы появятся в списке (их около 30–40, займёт минуту).

> Если GitHub ругается, что какой-то файл уже существует, — просто
> подтвердите замену.

## Шаг 4. Сохраняем (первый коммит)

1. Прокрутите страницу вниз до блока **Commit changes**.
2. В поле заголовка введите: `Первый релиз CDR Bridge` (любой текст).
3. Оставьте выбранным пункт **Commit directly to the main branch**.
4. Нажмите зелёную кнопку **Commit changes**.

Готово — код опубликован! Обновите страницу: вы увидите список файлов,
а ниже — красивое описание проекта из файла `README.md`.

## Шаг 5. Создаём релиз с портативной версией

«Релиз» — это раздел, где пользователи скачивают готовые файлы
(ваш «установочник»).

1. На странице репозитория справа найдите блок **Releases** → нажмите
   **Create a new release** (или «Draft a new release»).
2. В поле **Choose a tag** введите: `v1.0.0` и нажмите **Create a new tag: v1.0.0 on main**.
3. **Release title**: `CDR Bridge v1.0.0`.
4. В большое поле вставьте описание (готовый текст ниже ⬇).
5. Перетащите в поле «Attach binaries…» файл **CDR-Bridge-Portable.html**
   (и, если хотите, тот же архив `cdr-bridge-github.zip`).
6. Нажмите зелёную кнопку **Publish release**.

Готовый текст для описания релиза:

```text
Первая версия CDR Bridge.

Что внутри:
- CDR-Bridge-Portable.html — портативная версия: скачайте и откройте двойным кликом.
  Меняет версию .cdr-файлов офлайн, без установки, файлы никуда не отправляются.
- cdr-bridge-github.zip — исходный код полной веб-версии (конвертация в SVG/PDF/AI/PNG).

Как пользоваться портативной версией:
1. Скачайте CDR-Bridge-Portable.html ниже в разделе Assets.
2. Откройте файл двойным кликом (работает в Edge, Chrome, Яндекс.Браузере).
3. Перетащите в окно ваш .cdr — программа покажет его версию.
4. Выберите нужную версию (например, CorelDRAW 2017) и нажмите «Изменить версию».
5. Откройте скачанный файл в вашем CorelDRAW.
```

## Шаг 6. (Необязательно) Ссылка на портативную версию одной страницей

Чтобы любой посетитель мог открыть инструмент прямо с GitHub:

1. Вернитесь на главную репозитория → **Settings** (вкладка справа вверху).
2. Слева найдите пункт **Pages**.
3. В блоке «Build and deployment»: **Source** = `Deploy from a branch`,
   **Branch** = `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты появится адрес вида
   `https://ВАШ_ЛОГИН.github.io/cdr-bridge/`.
5. Портативная версия будет доступна по адресу
   `https://ВАШ_ЛОГИН.github.io/cdr-bridge/CDR-Bridge-Portable.html`
   — добавьте эту ссылку в описание репозитория (кнопка-карандаш справа от «About»).

## Шаг 7. (Необязательно) Полная версия онлайн через Vercel

Полная версия с конвертацией — это серверное приложение. Бесплатный хостинг Vercel
умеет запускать его прямо из вашего GitHub-репозитория:

1. Откройте **https://vercel.com** → **Sign Up** → **Continue with GitHub**
   (разрешите доступ).
2. Нажмите **Add New → Project**.
3. В списке найдите репозиторий `cdr-bridge` → нажмите **Import**.
4. Ничего не меняйте — просто нажмите **Deploy**.
5. Через 2–3 минуты получите адрес вида `cdr-bridge-xxx.vercel.app`
   — добавьте его в описание репозитория GitHub.

> При первом деплое Vercel спросит подтверждения — соглашайтесь
> (настройки по умолчанию подходят).

## Чек-лист перед публикацией

- [ ] Репозиторий называется понятно (например, `cdr-bridge`);
- [ ] В описании репозитория (About, шестерёнка справа) указано, что это и для кого;
- [ ] README.md открывается на главной странице и описание читабельно;
- [ ] Релиз v1.0.0 создан, `CDR-Bridge-Portable.html` прикреплён к Assets;
- [ ] Сами скачали портативную версию по своей ссылке и проверили, что она работает;
- [ ] (по желанию) ссылка GitHub Pages и/или Vercel добавлена в About.

## Если что-то пошло не так

- **Случайно загрузили лишний файл?** Откройте его в репозитории → кнопка-три точки
  справа → **Delete file** → Commit changes.
- **Ошиблись в названии репозитория?** Settings → General → самое верхнее поле
  **Repository name** → переименовать (старые ссылки сами перенаправятся).
- **Хотите удалить всё и начать заново?** Settings → General → прокрутите в самый
  низ → **Delete this repository** (потребует ввести название для подтверждения).
