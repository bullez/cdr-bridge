# CDR Bridge — смена версии файлов CorelDRAW + конвертация в Illustrator

**CDR Bridge** — бесплатный инструмент, который решает классическую проблему CorelDRAW: у вас стоит, например, CorelDRAW 2017 (v19), а файл прислали из CorelDRAW 2022 (v24) — программа пишет, что файл более новый, и отказывается его открывать.

CDR Bridge умеет:

1. **Изменять версию .cdr-файла** — например, из версии 24 сделать версию 19. Меняется только заголовок файла, поэтому **слои, объекты, текст и эффекты остаются нетронутыми** — ничего не перекодируется.
2. **Конвертировать .cdr в SVG, PDF, AI и PNG** — чтобы файл можно было открыть в **Adobe Illustrator** или импортировать в любой старый CorelDRAW («Файл → Импорт»). Слои и группы переносятся в результат.
3. **Определять версию файла** — просто перетащите .cdr в окно, и вы увидите, в какой версии он сохранён (поддерживаются как классические RIFF-файлы, так и ZIP-контейнеры CorelDRAW X6…2025).

## Вариант 1. Портативная версия (без установки) — самый простой путь

Если вам нужно **только поменять версию** `.cdr`-файла:

1. Перейдите в раздел [Releases](../../releases) этого репозитория.
2. Скачайте файл `CDR-Bridge-Portable.html`.
3. Откройте его двойным кликом в любом современном браузере (Chrome, Firefox, Edge).

Готово! Программа работает офлайн, файлы никуда не отправляются. Портативная версия умеет менять версию .cdr (функция №1).

> ⚠️ Портативная версия **не умеет конвертировать** в SVG/PDF/AI. Для этого нужна полная веб-версия (см. ниже).

---

## Вариант 2. Полная веб-версия (все функции)

Полная версия умеет всё, включая конвертацию в SVG/PDF/AI/PNG. Её можно запустить двумя способами:

- **Онлайн** — если автор проекта развернул её (ссылка в описании репозитория);
- **Локально на своём компьютере** — см. подробную инструкцию ниже.

## 📥 Установка для новичков (Windows)

Если вы никогда раньше не запускали проекты с GitHub — не пугайтесь. Всё, что нужно, — установить две бесплатные программы. Это займёт около 15 минут.

### Шаг 1. Установите Node.js

Node.js — это «движок», который нужен для работы CDR Bridge.

1. Перейдите на официальный сайт: **https://nodejs.org/**
2. Нажмите большую кнопку **LTS** (это самая стабильная версия). Скачается файл `.msi`.
3. Запустите скачанный файл и нажимайте **Next** (Далее), пока установка не завершится. Ничего менять не нужно.

### Шаг 2. Установите LibreOffice

LibreOffice — это бесплатный аналог Microsoft Office, но нам он нужен не для документов, а как «движок» для конвертации CDR-файлов в SVG/PDF/AI.

1. Перейдите на официальный сайт: **https://ru.libreoffice.org/download/**
2. Сайт обычно сам определяет вашу систему (Windows). Нажмите кнопку **Скачать**.
3. Запустите скачанный файл `.msi` и нажимайте **Next** (Далее), пока установка не завершится.

> 💡 Устанавливайте LibreOffice в папку по умолчанию (`Program Files`). Если поставить в другое место, программа может его не найти.

### Шаг 3. Скачайте и запустите CDR Bridge

1. На странице этого репозитория (GitHub) нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте скачанный архив в любую папку (например, на Рабочий стол).
3. Откройте папку с распакованными файлами. Внутри найдите файл `package.json`.
4. Кликните по пустому месту в папке правой кнопкой мыши, удерживая клавишу **Shift**, и выберите **«Открыть окно PowerShell здесь»** (или «Открыть командную строку здесь»).

   > Если этот пункт не появляется: нажмите `Win + R`, введите `cmd`, нажмите Enter. Затем перетащите папку с проектом в открывшееся чёрное окно — появится путь к папке. Введите `cd`, пробел и вставьте этот путь, нажмите Enter.

5. В открывшемся чёрном окне скопируйте и вставьте следующую команду, затем нажмите **Enter**:

   ```bash
   npm install
   ```

   Подождите, пока скачаются все компоненты. Это может занять пару минут.

6. После завершения введите следующую команду и снова нажмите **Enter**:

   ```bash
   npm run dev
   ```

7. В том же окне появится сообщение, что сервер запущен. Откройте ваш браузер и введите в адресную строку: **http://localhost:3000**

Готово! Теперь вы можете перетаскивать свои `.cdr` файлы в открывшееся окно браузера и пользоваться конвертацией.

### 💎 Что делать, если что-то пошло не так

- **Ошибка «npm не является внутренней или внешней командой»** — значит, Node.js не установился или установился неправильно. Перезагрузите компьютер и попробуйте снова (или переустановите Node.js).
- **Ошибка при конвертации (не работает SVG/PDF)** — убедитесь, что LibreOffice установлен именно в папку по умолчанию (`Program Files`).
- **Ничего не работает** — самый простой путь для новичка: использовать **портативную версию** (файл `CDR-Bridge-Portable.html`), которая умеет менять версию CDR, но не требует установки Node.js и LibreOffice.

## Как поменять версию файла (пример)

1. Откройте CDR Bridge и перетащите файл `banner-v24.cdr` в окно.
2. Программа покажет: «Версия 24 · CorelDRAW 2022 · контейнер ZIP».
3. Выберите целевую версию, например «CorelDRAW 2017 (v19)».
4. Нажмите «Изменить версию» и скачайте `banner-v24-v19.cdr`.
5. Откройте скачанный файл в вашей версии CorelDRAW.

## Почему это работает

Формат .cdr — это RIFF-контейнер. Версия файла хранится в одном символе заголовка: `RIFF....CDR**X**` (X — символ версии: `J` = 19 (2017), `O` = 24 (2022) и т. д.). Начиная с CorelDRAW X6 файл дополнительно завёрнут в ZIP-контейнер, внутри которого лежит тот же RIFF-поток (`content/riffData.cdr`).

CDR Bridge заменяет символ версии в заголовке — и всё. Содержимое документа не трогается, поэтому потери слоёв и объектов исключены в принципе.

**Честное ограничение:** если макет использует возможности, которых не было в целевой версии (новые типы заливок, линзы и т. п.), старая версия CorelDRAW может их упростить или не показать. Для таких случаев используйте конвертацию в SVG/PDF с последующим импортом.

## Запуск на своём компьютере (кратко для опытных)

Нужен [Node.js](https://nodejs.org) 20+ (или Bun) и LibreOffice Draw (движок конвертации; в Linux/Mac — пакет `libreoffice`, в Windows — [LibreOffice for Windows](https://www.libreoffice.org/download/)).

```bash
npm install
npm run dev
# откройте http://localhost:3000
```

Для продакшена:

```bash
npm run build
npm start
```

> Определение версии и смена версии работают без LibreOffice. Конвертация в SVG/PDF/AI/PNG требует установленного LibreOffice Draw (используются libcdr-фильтры импорта).

## Развёртывание онлайн (Vercel)

1. Запушьте репозиторий на GitHub.
2. Зайдите на [vercel.com](https://vercel.com) под аккаунтом GitHub.
3. «Add New → Project» → импортируйте репозиторий → «Deploy».
4. Готово — у проекта будет адрес вида `cdr-bridge.vercel.app`.

> ⚠️ Vercel по умолчанию не имеет LibreOffice, поэтому функция конвертации в облаке может не работать без дополнительной настройки среды.

## Технологии

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Собственный ZIP/RIFF-парсер на TypeScript (без внешних зависимостей)
- LibreOffice Draw / libcdr как движок конвертации

## Структура проекта

```
src/
  app/api/cdr/          API: analyze, convert, download, engine
  components/cdr/       Интерфейс (dropzone, версия, конвертация, FAQ)
  lib/
    cdr-versions.ts     Таблица версий CorelDRAW
    cdr-analyze.ts      Определение формата и версии
    cdr-container.ts    ZIP-ридер для контейнеров X6+
    cdr-patch.ts        Смена версии + ZIP-сборщик
    cdr-engine.ts       Движок конвертации (LibreOffice)
    svg-sanitize.ts     Очистка SVG-экспорта LibreOffice
```
